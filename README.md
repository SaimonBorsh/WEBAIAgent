# WEBAIAgent — веб-менеджер ИИ-агента на базе opencode

Веб-интерфейс для управления процессами `opencode serve` из браузера: создание проектов (папок с кодом), свой локальный сервер opencode на каждый проект, живой чат с агентом через SSE (в т.ч. со смартфона), прикрепление файлов, разрешения на действия (bash/edit/write), инициализация проекта (генерация AGENTS.md), настройка модели и параметров для каждой сессии, бесплатные модели без API-ключей.

## Возможности

- **Проекты** — создание (название + папка), запуск/остановка одной кнопкой, авто-старт, иконки с авто-тоном, архив, переименование, удаление (только из архива; папки на диске не трогаются).
- **Сессии** — список с группами «Активные»/«Архив», создание, настройка (модель, агент, temperature/topP/maxTokens, системный промпт), переименование, архивирование, удаление (только из архива). Выбор сессии запоминается в localStorage.
- **Чат** — живой стриминг через SSE (текст, рассуждения, инструменты), статус агента с таймером («Думает…»/«Выполняет…»/«Печатает…»), кнопки «Остановить»/«Продолжить», очередь сообщений, повторить запрос, копирование кода, вложения (📎 + drag-drop, до 5 МБ, docx-текст извлекается на сервере), вопросы и разрешения агента, виртуализация длинных сессий.
- **Инициализация** — агент анализирует проект и создаёт AGENTS.md (проверено).
- **Настройки** — глобальные (тема, плотность, показ модели/токенов/рассуждений, пароль, автозапуск браузера) и на уровне проекта (модель/агент/параметры по умолчанию, системный промпт, авто-старт, иконка).
- **Бесплатные модели** — список подтягивается с models.dev (кэш 6 ч), при недоступности — локальный запасной список.
- **Версии** — переносимая установка (дистрибутив `WEBAIA`), установка/активация/откат версий через веб-UI.
- **Мобильная адаптивность** — вертикальный скролл чата, bottom-sheet модалки, safe-area, защита от авто-зума iOS.

## Запуск и сборка

Требуется Node.js 18+ (проверено на 24) и установленный CLI `opencode` (см. `server/src/manager.js` — ищется через `where.exe`, затем в `%APPDATA%\npm\node_modules\opencode-ai`).

```bash
npm install          # postinstall автоматически собирает web/ (tsc + vite build)
npm start            # продакшен: сервер на :3720, раздаёт собранный web/dist, открывает браузер
npm run dev          # dev: сервер (node --watch) :3720 + Vite :5173 (проксирует /api на 3720)
npm run build        # сборка web/ (это же typecheck)
npm run serve        # = node scripts/keepalive.js (watchdog с авто-перезапуском менеджера)
npm run backup       # снапшот в backups/<метка>/ (npm run backup -- <метка>)
```

Тестов, линтера и CI нет. Typecheck = `npm run build --workspace=web`. Серверная часть — обычный JS (ESM), без typecheck.

## Структура (npm-workspaces)

- `server/` — Express, JavaScript ESM, единственная зависимость — express. Точка входа `server/src/index.js`.
  - `index.js` — REST-маршруты менеджера + `RUSSIAN_INIT_PROMPT`, `fetchOpenCode()`, прокси-ловушка на `/api/projects/:id`.
  - `manager.js` — жизненный цикл `opencode serve --port N --hostname 127.0.0.1`, health-check, поиск exe.
  - `registry.js` — персистентный реестр проектов в `server/projects.json` + `sessionConfig`/`archivedSessions`/`defaults`/`icon`/`iconTone`.
  - `proxy.js` — прокси REST/SSE к серверу проекта, чистка hop-by-hop заголовков.
  - `models.js` — список бесплатных моделей с models.dev + fallback.
  - `auth.js` — токены (`tokens.json`, TTL 30 дней), `authMiddleware`, смена пароля (SHA-256).
  - `settings.js` — глобальные настройки (`settings.json`).
  - `versions.js` — управление версиями переносимой установки (list/switch/upload).
  - `fsbrowse.js` — обход ФС для пикера папок/файлов.
  - `scripts/keepalive.js` — watchdog авто-перезапуска менеджера (бэкофф 1–30с, kill через taskkill /T, `WEBAIA_WATCH=1` для hot-reload).
  - `scripts/publish.cjs` — сборка переносимого дистрибутива (esbuild-бандл, portable Node, opencode.exe, zip).
- `web/` — React 18 + Vite + TypeScript (strict). `web/src/api.ts` — единый API-клиент + SSE-подписка (`EventSource ?token=`). Типы opencode — в `web/src/types.ts`.

## Авторизация

- Логин/пароль: `admin`/`root` (переопределяются `WEBAIA_USER`/`WEBAIA_PASS`; пароль можно сменить в настройках).
- Передача токена: `Authorization: Bearer <token>` или `?token=<token>` (обязателен для SSE/EventSource).
- Публичны только `GET /api/health` и `POST /api/login`. CORS открыт полностью; менеджер без HTTPS.

## Неочевидные требования

- Сессии opencode глобальные (на всю машину); интерфейс фильтрует их по `directory === project.path`.
- Серверы проектов привязаны только к 127.0.0.1; порты 4100–4199 выдаются автоматически.
- Модель по умолчанию: `opencode/deepseek-v4-flash-free`, агент `build`. Без провайдера подставляется префикс `opencode/`.
- Отправка сообщений — через `prompt_async` (fire-and-forget), события идут по SSE.
- Вложения: локальный URL `file:///...` через `POST /api/upload`; docx извлекается в `.txt` на сервере.
- Перед изменениями обязателен бэкап: `node scripts/backup.js v<N>`.
- Полное техническое состояние и история — в `JOURNAL.md`, дизайн-анализ — в `design/`.

## Переносимая установка (дистрибутив)

`publish/WEBAIA-v<NN>.zip` — самодостаточный пакет (portable Node.js, opencode.exe, сервер-бандл, собранный фронтенд). Распаковать и запустить `start.cmd` без установки Node.js и opencode. Версии в `versions/`, активация через `current.txt`, данные в `data/`.
