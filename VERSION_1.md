# Версия 1 — WEBAIAgent

Рабочее решение готово и протестировано end-to-end. Менеджер запущен на http://127.0.0.1:3720.

## Возможности

- **Проекты** — создание (название + папка), запуск/остановка одной кнопкой, авто-старт, выбор модели по умолчанию.
- **Сессии** — список, создание, удаление, история сообщений.
- **Чат** — живой стриминг через SSE (текст, «рассуждения», вызовы инструментов), кнопка «Остановить», запросы разрешений («Разрешить / Всегда разрешать / Запретить»).
- **Инициализация** — агент анализирует проект и создаёт `AGENTS.md` (проверено — файл создаётся).
- **Бесплатные модели** — 27 бесплатных моделей провайдера `opencode` (без ключей, за $0), список подтягивается с models.dev, при недоступности — локальный запасной список.

## Проверено end-to-end

- создание проекта, авто-запуск сервера opencode
- чат с `deepseek-v4-flash-free` (ответил)
- SSE-стриминг событий
- init → AGENTS.md
- кириллица

## Структура

- `server/` — Express: реестр в `projects.json`, управление процессами `opencode serve`, прокси REST/SSE, список моделей.
- `web/` — React + Vite + TS, русский интерфейс (дашборд, проект, чат).

## Запуск

```bash
npm start        # продакшен: сервер :3720 + собранный фронтенд, открывает браузер
npm run dev      # разработка: сервер :3720 + Vite :5173
```

## Известные особенности

- Сессии opencode хранятся в общей БД; интерфейс фильтрует их по папке проекта (`directory`).
- Серверы привязываются к 127.0.0.1, локально.
- Запрос `POST /session/{id}/init` блокирует до завершения анализа — в менеджере вызывается fire-and-forget, чтобы UI отвечал мгновенно.
